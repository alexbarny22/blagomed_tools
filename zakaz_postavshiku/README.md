# Заказ поставщику из Excel → 1С УТ

> **Восстановлено из переписки (01.11.2026).** Файлы собраны повторением всех правок из чата
> «Бот для заказа поставщику из Excel» (29.10.2026). Это должна быть последняя версия —
> с PDF и кнопкой «Отправить поставщику в МАКС» через буфер обмена. Перед заменой рабочей
> версии сверьте с той, что стоит на компьютере.

## Что делает
Программа с окном на клиентском компьютере. Берёт Excel-отчёт («Заказ_Отчет.xlsx»), колонки
**Номенклатура** и **Заказ** (и **Склад**, если есть), находит товары в 1С через OData
(публикация `ut12`), создаёт «Заказ поставщику» на ГАВРЮШКИН Р.Н. и проводит его.

- Статус — «Подтвержден», дата поступления — дата заказа + 1 месяц (`срок_поступления_мес`).
- Цена: регистр цен поставщика → цена из прошлых заказов этому поставщику → 0 (жёлтая строка).
- Шапка (валюта, НДС, этапы оплаты) копируется из последнего заказа поставщику.
- После проведения сохраняет PDF в папку `Заказы` рядом с ботом (копия — `[PDF] копия =`).
- «Сохранить PDF» — PDF по номеру уже созданного заказа (`00ЦБ-000031` или просто `31`).
- «Отправить поставщику в МАКС» — кладёт PDF в буфер обмена, затем текст «Заказ № …»;
  вы вставляете их Ctrl+V в свою переписку с поставщиком.

## Установка
1. Скопируйте папку на компьютер.
2. Переименуйте `config.example.ini` в `config.ini` и впишите логин и пароль 1С (`user`, `password`).
3. Запустите `start.bat` — сам найдёт Python (или поставит), доустановит библиотеки.
   Если Python не находится — один раз запустите `Прописать_Python.bat`.

## Если 404 / «не включён в состав OData»
1С → НСИ и администрирование → Синхронизация данных → «Настройки стандартного интерфейса OData» →
вкладка «Состав» → галочки: документ «Заказ поставщику»; справочники Контрагенты, Номенклатура,
Организации, Склады, Соглашения с поставщиками, Договоры с контрагентами, Виды цен поставщиков;
регистр «Цены номенклатуры поставщиков» → «Сохранить и закрыть».

Без окна (проверка): `python zakaz_postavshiku.py "Заказ_Отчет.xlsx" 29.10.2026`
