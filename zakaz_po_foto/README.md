# Заказ клиента по фото этикеток (Telegram → 1С через COM)

> **Восстановлено из переписки (01.11.2026)** — чат «Бот для распознавания товаров и создания
> заказов в 1С» (19.09.2026). Это версия, выданная в конце чата; была ли она запущена в работу
> и менялась ли после — неизвестно. Перед использованием сверьте.

## Что делает
Фотографируете этикетку коробки (`МН-01` / `24 шт.` / `(ВБ)`), бот распознаёт код, количество
и маркетплейс, копит коробки в корзину. Одинаковые складываются («3 кор. × 24 = 72 шт.»).
По «Готово» создаёт в 1С **непроведённые** «Заказы клиента» — отдельно на партнёра ВБ и Озон.
Шапка копируется с последнего заказа этого партнёра. Цены — нули, менеджер жмёт «Заполнить цены».
Незнакомый код бот спросит один раз и запомнит в `codes.json`.

## Установка (Windows-машина с платформой 1С)
1. Tesseract с русским языком: github.com/UB-Mannheim/tesseract/wiki
   (Additional language data → Russian).
2. `pip install -r requirements.txt`
3. `config.example.ini` → `config.ini`, заполнить пароль 1С, токен Telegram-бота, свой ID,
   партнёров ВБ/ОЗ ровно как в справочнике «Партнёры».
4. В 1С должен быть хотя бы один заказ на каждого партнёра (образец шапки).
5. `python check_com.py` — проверка связи (только читает).
6. По желанию: коды в `codes.csv` → `python import_codes.py`.
7. `python bot.py`

`python label.py фото.jpg` — проверить распознавание без бота.
COM: нужна зарегистрированная `comcntr.dll`, разрядность Python = разрядности 1С.
