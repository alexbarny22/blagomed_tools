# Как пользоваться:
#  • Один ответ = одна строка. Пишите сколько угодно вариантов, бот выберет случайный.
#  • Приветствие бот берёт из раздела «Приветствие» (случайное) и ставит в начало ответа сам.
#    [имя] — имя покупателя. Если имени нет, бот уберёт его сам: получится «Здравствуйте.».
#    Если начать ответ со своего «Здравствуйте» или «Добрый день» — приветствие не добавится.
#  • Можно вставить [товар] — бот подставит название товара.
#  • Раздел «без текста» — для отзывов, где покупатель поставил только звёзды.
#    Если он пустой, бот возьмёт ответы из обычного раздела.
#  • Чтобы бот НЕ отвечал на какую-то оценку — удалите все ответы из её раздела.
#  • Строки, которые начинаются с #, бот не читает (это заметки).
#  • Не пишите телефоны, ссылки и названия других площадок — WB такие ответы не пропускает.
#  • Строки с === не трогайте: это заголовки разделов.
#
# После правки просто сохраните файл (Ctrl+S). Бот подхватит изменения сам.
