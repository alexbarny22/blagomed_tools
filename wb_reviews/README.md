# Автоответы на отзывы Wildberries

> **Восстановлено из переписки (01.11.2026)** — чат «Бот автоотзывов на Wildberries» (28–29.10.2026).
> Повторены все правки по порядку: ответы в `otvety.txt`, сухой тон, приветствия, чтение токена
> в любой кодировке. Перед заменой рабочей версии на сервере сверьте с ней.

## Что делает
Работает постоянно (под менеджером ботов / BotPanel). Раз в `interval_min` минут (по умолчанию 30)
забирает неотвеченные отзывы WB и отвечает по оценке 1–5 случайным вариантом из `otvety.txt`.
Один и тот же вариант подряд не повторяет. Пишет `heartbeat_wb_reviews.txt` («я жив»)
и журнал `wb_reviews.log` в своей папке.

## Установка (Windows Server)
1. Папку `wb_reviews` положите рядом с другими ботами.
2. Переименуйте `wb_reviews_config.example.json` в `wb_reviews_config.json`, вставьте токен WB
   (кабинет WB → Настройки → Доступ к API → категория «Вопросы и отзывы», **без** «Только на чтение»).
3. `test_wb_reviews.bat` — пробный проход: показывает ответы, ничего не отправляет.
4. В `wb_reviews_config.json` поставьте `"dry_run": false`.
5. Запуск постоянной работы: `python wb_reviews_bot.py` (в BotPanel — путь к этому файлу).

## Тексты ответов — `otvety.txt`
Разделы `=== Приветствие ===`, `=== Подпись ===`, `=== 1 звезда ===` … `=== 5 звёзд без текста ===`.
Одна строка — один вариант. `[имя]`, `[товар]` подставляются. Пустой раздел — на эту оценку бот
не отвечает. Правки подхватываются без перезапуска.

Запуск: `python wb_reviews_bot.py` (постоянно) · `--once` (один проход) · `--test` (только показать).
