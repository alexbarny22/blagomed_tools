## Этап 7.1: наценка по умолчанию и запуск

- Причина ошибки `0,15%` устранена: `[Расчёт]` в `config.ini` — справочный
  раздел и не является источником настроек БД. Первичная инициализация
  выполняется в `app/web/store.py::create_db` и записывает единые начальные
  значения `INITIAL_SETTINGS` из `app/core/migrate.py`: ППУ 405 ₽/кг,
  наценка **15%**, порог 10%, дата начала 2026-07-01. Legacy-импорт использует
  те же константы.
- `config.example.ini`: `margin_pct = 15` (проценты, не доля `0,15`).
- Новая БД: 1000 ₽ + 15% = **1150 ₽**; страница «Расходы» показывает
  `15,00%`, а не `0,15%`. Исторические значения и формула с `ROUND_FLOOR`
  не изменялись.
- `start.bat`/`stop.bat`/`env-check.bat` работают только с каталогом самого
  BAT; автоматического переключения на `C:\Blagomed\SebestoimostMP` больше
  нет. Явный каталог задаётся `BLAGOMED_BASE`. Проверяются обязательные
  файлы, занятость порта, уже запущенный экземпляр и Python (venv → PATH).
- Новый `install.bat`: venv, pip, `requirements.txt`, создание `config.ini`
  из примера при отсутствии. База данных не создаётся ни установщиком,
  ни `start.bat` — только явно на странице «База данных».

## Адрес и запуск

- Локально: `install.bat` → заполнить `config.ini` → `start.bat` →
  `http://127.0.0.1:8085` (порт из `config.ini`). Без `config.ini`
  `start.bat` не запускается и печатает точную команду исправления.
- `start.bat`, `stop.bat`, `env-check.bat` работают с каталогом самого BAT;
  явный каталог — через `BLAGOMED_BASE`. Автопереключения на чужую копию нет.
- С другой машины: в `config.ini` указать `[web] host = 0.0.0.0`,
  разрешить TCP-порт 8085 в брандмауэре для доверенной подсети и открыть
  `http://<IP-сервера>:8085`. Передача HTTP без TLS — только доверенная
  сеть/VPN.
- Остановка: `stop.bat`. Диагностика: `env-check.bat`,
  `python tools/web_control.py status`.
- Вход обязателен: без `[auth] user/pass_hash` все разделы закрыты; пароль
  хранится только хэшем (`python tools/hash_password.py`).
