## Адрес и запуск

- Локально: `start.bat` → `http://127.0.0.1:8085` (порт из
  `config.example.ini`; без `config.ini` действует резервный порт 8000).
- С другой машины: в `config.ini` указать `[web] host = 0.0.0.0`,
  разрешить TCP-порт 8085 в брандмауэре для доверенной подсети и открыть
  `http://<IP-сервера>:8085`. Передача HTTP без TLS — только доверенная
  сеть/VPN.
- Остановка: `stop.bat`. Диагностика: `env-check.bat`,
  `python tools/web_control.py status`.
- Вход обязателен: без `[auth] user/pass_hash` все разделы закрыты; пароль
  хранится только хэшем (`python tools/hash_password.py`).
