## 1С: правила сопоставления и источника цены (этап 5)
- Приоритет: GUID → наименование → артикул-подсказка. GUID первичен даже при
  изменённом артикуле; неверный GUID при совпавшем артикуле → NOT_FOUND.
- Несколько разных кандидатов с одним GUID → AMBIGUOUS; совпадение ТОЛЬКО по
  артикулу → NEEDS_CONFIRM (цена приложена, НЕ объявлена).
- Источник цены: exact → вид+владелец → vid_only → any → fallback_register.
  Не-exact → NEEDS_CONFIRM. Цена None нулём не заменяется; ошибки соединения
  → AUTH/CONNECT_ERROR/TIMEOUT (не NOT_FOUND). COM — основной источник цен,
  OData — вспомогательный источник GUID (цены N/A); merge_odata_guid: разные
  GUID → AMBIGUOUS, цена не допускается.
