## Правило доп. расходов (владелец, 07.11.2026)
- Новая запись той же статьи заменяет предыдущую с даты valid_from; разные статьи
  суммируются. Пример: «Поролон» 100 ₽ с 01.07, новая 120 ₽ с 01.11, «Упаковка» 25 ₽
  с 01.07 → 15.10: 125 ₽; 15.11: 145 ₽; старая 100 ₽ остаётся в истории.
- Закрытая запись (valid_to <= даты) не возобновляется: более ранняя с valid_to=NULL
  не возвращается. Выбор записи — последняя по valid_from, при равенстве — больший id.

  SQLite и формула себестоимости (ППУ, наценка, ручные цены) не изменялись; ядро
  только читает extras, строки не редактируются.
