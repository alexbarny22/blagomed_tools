## БИЗНЕС-ПРАВИЛА
1. Себестоимость единая для OZON и WB. Закупочная цена — актуальная из 1С УТ 11.5. Запуск только вручную.
2. Формула: floor((Цена1С + ВесППУ_г/1000 × ЦенаППУ_кг + Σ ДопРасходы) × (1 + Наценка)).
   - ЦенаППУ_кг — сейчас 405 ₽, меняется; хранится с датой начала действия.
   - Наценка — сейчас 15% (аренда, ЗП, свет, ГСМ, прочее); хранится с датой начала действия.
3. «Вес ППУ, г» — поле есть у ЛЮБОГО товара; пусто = 0.
4. «Дополнительные расходы» — у любого товара 0..N строк «статья + сумма ₽», вводятся вручную (поролон, упаковка и т.п.). Справочник статей расширяемый.
5. Товары другого поставщика (FIXED_COSTS старого бота) — признак «ручная закупочная цена» у товара, цена вводится в интерфейсе с датой.
6. Артикулы 1С ненадёжны: ключ сопоставления — GUID 1С (Ref_Key), резерв — наименование (нормализация регистр/пробелы/ё→е). Артикул — подсказка.
7. 1С: COM V83.COMConnector (подключение ~3.5 мин, одно на запуск) или OData http://<сервер>:4001/ut12/odata/standard.odata/ — по решению этапа 0.

## ЭТАП 3. База данных (SQLite, stdlib sqlite3, без ORM)

## ЭТАП 7. Веб-интерфейс (Flask, вход по логину, пароль хэшем в config)
- «Расчёт»: загрузка отчётов, кнопка «Рассчитать» (фоновый поток, статус, хвост лога), скачивание файлов; повторный запуск блокируется, пока идёт текущий.
- «Товары»: таблица с колонками Артикул 1С | Наименование | WB | OZON | Вес ППУ, г (редактируется прямо в таблице) | Доп. расходы ₽ (сумма, клик → карточка) | Закупка | Себестоимость | Δ%. Фильтры: с ППУ / с доп. расходами / без цены / новые.
- Карточка товара: вес ППУ, строки доп. расходов (добавить/изменить/удалить, дата начала), ручная цена, история изменений, график себестоимости товара.
- «Настройки»: цена ППУ за кг, наценка %, порог алерта — с датой начала действия и историей.
- «История запусков»: список runs, скачивание файлов любого запуска.
Все правки → audit_log. Валидация: вес 0–10000 г, суммы ≥0.
Приёмка: полный цикл через браузер с другой машины; без входа доступа нет.
