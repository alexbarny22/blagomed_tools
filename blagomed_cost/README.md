# Расчёт себестоимости МП (`blagomed_cost.py`)

> **Восстановлено из переписки (01.11.2026)** — чаты «Формирование прайса с закупочными ценами»
> (май 2026) и «Синхронизация артикулов WB при добавлении новых позиций» (июнь 2026).
> Повторены все правки до финальной версии, которая в чате сошлась с отчётом «Условия закупок»
> один в один. Перед заменой рабочей версии в `C:\bot\СебестоимостьМП` сверьте.

## Что делает
Раз в месяц формирует два файла:
- `себестоимость_контроль_ГГГГ_ММ.xlsx` — детальный расчёт, подсветка резких изменений (±10%);
- `Благомед_себестоимость_ГГГГ_ММ.xlsx` — файл для загрузки в сервис аналитики.

Формула: `floor((закуп + вес_г/1000 × 405 + доп.расходы) × 1.15)`.

## Откуда цены
1. **1С (основной режим, COM)** — регистр «Цены номенклатуры поставщиков», вид «Закупочная»,
   поставщик ГАВРЮШКИН (как отчёт «Условия закупок»); дубли схлопываются по последнему периоду.
   Добор — регистр «Цены номенклатуры», затем цена последнего поступления.
2. **PDF (резервный)** — `отчет.pdf` из 1С в папке скрипта. Если PDF лежит, из него всегда
   дополняются веса.
3. `FIXED_COSTS` в скрипте — 20 позиций другого поставщика.

## Файлы-память (не удалять, в гит не попадают)
- `wb_catalog.json` — список позиций (артикул WB ↔ поставщика). Пополняется из свежего шаблона
  сервиса `Благомед_Себестоимость_ММ_ГГГГ.xlsx`, положенного в папку.
- `cost_history.json` — прошлая себестоимость для алертов.
- `weights.json` — веса, г (в гите — стартовые 15 позиций; нет веса = не участвует в расчёте).
- `config.ini` — создаётся сам при первом запуске; вписать сервер (лучше IP), базу, логин, пароль 1С.

## Установка
`pip install pdfplumber openpyxl pywin32`, затем двойной клик по `blagomed_cost.py`.
Для COM: разрядность Python = разрядности 1С, зарегистрированная `comcntr.dll`.
Подключение по COM ~3 минуты — это известно, на месячном запуске терпимо.
