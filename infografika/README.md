# infografika — генератор инфографики Благомед

Программа в браузере: по фото и описанию товара делает серию из 5 слайдов 900×1200 для WB и Ozon
(с 1–3 вариантами обложки) и тексты карточки — названия и описания отдельно для WB и Ozon.
Нейросети — через vsellm.

## Запуск

1. Выключите VPN (vsellm работает только без него).
2. Двойной щелчок по `start.bat`. Программа сама обновится, поставит библиотеки и шрифты,
   откроет страницу в браузере. Если в config.py нет ключа — откроется Блокнот, впишите
   `VSELLM_KEY = "..."`, сохраните и запустите снова.
3. Чтобы закрыть программу — закройте чёрное окно.

## Как работает

1. **Новая серия:** фото товара (2–4), описание из карточки (полезно добавить отзывы),
   стиль (автоподбор / как у конкурентов / из библиотеки / словами), 1–3 обложки, профиль, потолок.
2. Сценарист пишет ключевые запросы, сценарий 5 слайдов и тексты WB/Ozon (≈ 8–10 ₽).
3. **Вы проверяете и правите:** ключи, тексты слайдов, размеры, тексты карточки, цвета и шрифт.
4. «Запустить генерацию»: нейросеть рисует по фото товара, контролёр проверяет совпадение товара,
   брак перерисовывается (другой нейросетью профиля), текст накладывается кодом.
5. Результат: «Текст и вид» — правка надписей и вёрстки бесплатно; «Переделать» — новая картинка с пожеланием;
   «Стиль серии» — шрифт, цвета, эффекты всей серии бесплатно; «Открыть папку» — готовые PNG и `тексты.txt`.

## Вёрстка (конструктор)

Каждый слайд собирается из элементов, у каждого есть варианты:
- **заголовок:** классика, главное слово огромно, двухцветный, тонкая строка + жирное слово, на ленте,
  цифра главная, внизу на затемнении; выравнивание, регистр, разрядка, курсив, обводка, тень, градиент;
- **подзаголовок:** обычный, на белой ленте, на плашке, на капсуле;
- **фото:** во весь слайд, полосами, в рамке-карточке;
- **преимущества/пункты:** колонкой с иконками, списком, сеткой 2×2, вразброс; иконки залитые или контурные;
- **бейдж:** круг, звезда, круг с текстом по дуге, лента-уголок; **слоган** внизу; **метка-табличка**.

Сценарист выбирает вид сам или повторяет образцы конкурентов. Всё переключается вручную бесплатно:
на шаге утверждения, кнопкой «Текст и вид» у слайда или «Стиль серии» для всех слайдов.
Элементы обходят товар (его положение сообщает контролёр).

## Профили

- **Эконом** — GPT Image 2. **Баланс** — Nano Banana 2 + GPT Image 2. **Максимум** — Nano Banana Pro.
- **Ультра** — новейшие модели OpenAI: картинки GPT Image 2.5 (sunburst → flare) в качестве high,
  сценарий и тексты GPT-6 Astra, проверка GPT-6.1 Sol. Потолок по умолчанию 300 ₽.
  Цены GPT Image 2.5 в настройках — оценка; после первого прогона поправьте по журналу списаний vsellm.

## Деньги

- Шкала «Потрачено / потолок» вверху. При достижении потолка — пауза и вопрос:
  добавить сумму или остановиться (готовое сохраняется, недостающее можно дорисовать позже).
- vsellm берёт деньги и за неудачные попытки — программа их тоже считает.
- Цены за картинку (фактические на 01.11.2026): Nano Banana 2 — 7,69 ₽, GPT Image 2 — 6,03 ₽,
  Nano Banana Pro — 15,73 ₽. Меняются на странице «Настройки».

## Файлы

- `projects\` — все серии (папка `готово` внутри каждой — итоговые слайды и тексты).
- `settings.json`, `styles.json` — ваши настройки и сохранённые стили.
- `config.py`, `settings.json`, `styles.json`, `projects\` в GitHub не попадают.
