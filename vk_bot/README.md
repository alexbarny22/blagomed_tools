# vk_bot — VK-бот Благомед

Один процесс обслуживает два сообщества ВКонтакте:

- «Прокат средств реабилитации» (группа 168264636) — каталог и цены из `https://blagomedi.ru/rental.json`
- «Прокат фотоламп» (группа 177921324) — фотолампы из Google-таблицы

## Файлы в папке на сервере

| Файл | Откуда | Обновляется сам |
|---|---|---|
| `VK_bot.py` | репозиторий | да |
| `update.py`, `deps.py`, `config.example.py` | репозиторий | да |
| `start.bat` | репозиторий | нет (меняется редко) |
| `config.py` | только на сервере — токены сообществ | никогда |
| `credentials.json` | только на сервере — ключ Google для фотоламп | никогда |
| `VK_bot.log` | журнал | — |

## Обновление

При запуске и каждую ночь в 03:00 бот сверяет `version.txt` с папкой `vk_bot` в репозитории.
Если версия новее — скачивает файлы из `manifest.txt`, завершается с кодом 3, и BotPanel
(или цикл в `start.bat`) запускает его уже новым.

## Запуск

- В BotPanel: команда `python VK_bot.py`, рабочая папка — папка бота.
- Вручную: `start.bat` (сам перезапускает бота при остановке).

## Пункты проката

Список — `RENTAL_STORES` в `VK_bot.py`. У нового пункта можно указать `open_from` (дата открытия):
до этой даты бот пишет «откроется …», после — показывает пункт как обычный.
