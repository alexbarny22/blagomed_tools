## Что сделано

- `app/onec.py`, `app/_com_worker.py` — вендоренный (без изменений логики) перенос из проверенного `blagomed_cost/app/core/` (ТЗ §7): сопоставление GUID → наименование (ё→е) → артикул (только подсказка); статусы OK/NO_PRICE/NOT_FOUND/AMBIGUOUS/NEEDS_CONFIRM/AUTH_ERROR/CONNECT_ERROR/TIMEOUT/NOT_AVAILABLE/ERROR; COM через контролируемый подпроцесс с реальными таймаутами (300 с + 120 с, родитель убивает процесс); OData — только справочник (цены не публикуются, HTTP 501 на RecordSet), честный NOT_AVAILABLE вместо выдуманных цен.
- `app/price_source.py` (новый) — адаптер приложения: `load_params` (config.ini → Params + mode; None, если файла нет) и `fetch_prices(products, params, mode)` → `(prices, errors)`; любое исключение источника → всем внешним товарам «1С недоступна: …», приложение не падает.
- `app/calc_run.py` — `run_calculation` принимает `prices`/`price_errors`: ошибка цены → проблемная позиция с текстом причины; цена из 1С → расчёт с `price_source='1c'`.
- `app/web/routes.py` — `/calc`: товары с `manual_price=0` идут в 1С; нет config.ini или 1С недоступна → flash-предупреждение + проблемные позиции, ручные товары считаются; `manual_price=1` в 1С не ходит.
- `config.example.ini` — шаблон [1C] (mode/server/base/user/password/url_odata) и [Цены] (вид_цены=Закупочная, поставщик=ГАВРЮШКИН); config.ini с паролем в git не коммитится.
- Тесты: `test_price_source.py` (7). Всего **39/39 зелёных**.
