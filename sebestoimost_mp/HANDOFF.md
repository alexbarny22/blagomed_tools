## Запуск и тесты
```
pip install flask waitress openpyxl pywin32  # pywin32 только на Windows (1С COM)
cd sebestoimost_mp
python -m pytest tests/ -q        # 47 тестов
python run.py                     # 127.0.0.1:8085
```
Без config.ini приложение работает в деградации: расчёт помечает позиции «1С не настроена».

## Жёсткие инварианты (не нарушать)
- Формула: `floor((закупка + вес_г/1000 * ППУ + допы) * (1 + наценка/100))`, Decimal.
  Контрольный пример: 1000 ₽ + 200 г × 405 ₽/кг + 50 ₽, наценка 15% -> 1300.
- 1С — строго read-only. CONNECT_ERROR != NOT_FOUND.
- Цены NEEDS_CONFIRM / AMBIGUOUS никогда не подставляются автоматически.
- Неизвестная цена != 0.
- SQLite LOWER() — только ASCII; поиск по кириллице — на Python.
- secure_filename кириллицы теряет расширение — `.xlsx` добавляется принудительно (см. этап 5).
