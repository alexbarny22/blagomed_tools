# Этап 7 — Сквозной сценарий (E2E), 12 шагов

Выполняется на Windows-машине владельца с доступом к боевой 1С УТ 11.5.
Песочница это проверить не может (COM только на Windows) — прогон за владельцем.
Чекбоксы отмечать по факту; любой сбой — стоп, записать шаг и сообщение.

- [ ] 1. Скопировать папку `sebestoimost_mp/` на машину (путь может содержать пробелы и кириллицу).
- [ ] 2. Запустить `INSTALL.cmd`: создаётся venv, ставятся зависимости, появляется `config.ini`; ошибок нет.
- [ ] 3. Заполнить `config.ini` (server, base, user, password — пользователь 1С ТОЛЬКО с правами чтения).
- [ ] 4. Запустить `START.cmd`: сервер поднимается, браузер открывает http://127.0.0.1:8085.
- [ ] 5. На главной загрузить реальные файлы WB («Себестоимость за 2026-11») и Ozon; на главной видны имена загруженных файлов (кириллица).
- [ ] 6. «Товары»: список заполнился; поиск по кириллице (напр. «крем») находит позиции.
- [ ] 7. «Расходы и настройки»: проверить/задать ППУ, наценку 15%, доп. расходы.
- [ ] 8. На главной выполнить расчёт на текущий месяц; дождаться итогов (всего/рассчитано/проблем).
- [ ] 9. Контрольный пример: позиция с закупкой 1000 ₽, весом 200 г (ППУ 405 ₽/кг), допами 50 ₽, наценка 15% → в выгрузке ровно 1300 ₽.
- [ ] 10. Скачать заполненные файлы WB и Ozon: записаны ТОЛЬКО целевые столбцы (WB — E, Ozon — D), остальное и оригиналы не изменены.
- [ ] 11. «Проблемные»: позиции без цены в 1С перечислены с причинами; задать цену вручную → возврат на «Проблемные», пересчёт → позиция исчезает. Цены NEEDS_CONFIRM/AMBIGUOUS автоматически не подставлялись.
- [ ] 12. «История»: прогоны видны с итогами. `STOP.cmd` останавливает сервер.

Инварианты прогона: 1С только чтение; при недоступной 1С — позиции уходят в проблемные с причиной «1С не настроена/недоступна», приложение не падает; неизвестная цена ≠ 0.
