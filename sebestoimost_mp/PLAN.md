## Архитектура (без расширения ТЗ)
- Новый чистый модуль `sebestoimost_mp/` рядом с прежним `blagomed_cost/` (не трогаем).
- Стек: Python 3, Flask, Waitress, SQLite, openpyxl, простой HTML/CSS/JS. Минимум зависимостей.
- Тестовый режим: 127.0.0.1:8085, без авторизации, SQLite создаётся автоматически.
- Windows: `INSTALL.cmd`, `START.cmd`, `STOP.cmd` (CRLF, OEM-кодировка вывода, пробелы в путях).

## Структура модуля
- `run.py` — точка входа (waitress, 127.0.0.1:8085, открытие браузера).
- `app/__init__.py` — фабрика Flask-приложения.
- `app/db.py` — SQLite: схема, PRAGMA user_version, автосоздание, без перезаписи.
- `app/calc.py` — формула `floor((цена + вес/1000*ППУ + доп.расходы) * (1 + наценка/100))`, Decimal, ROUND_FLOOR; версионирование по датам (правила прежнего calc.py).
- `app/excel_io.py` — адаптеры WB/Ozon: чтение артикулов, запись только целевых ячеек, сохранение оригинала.
- `app/onec.py` — чтение закупочных цен из 1С УТ 11.5 (COM/OData, только чтение); при недоступности — ручные цены, приложение не падает.
- `app/web/` — страницы: Расчёт, Товары, Расходы и настройки, Проблемные позиции, История (компактная).
- `tests/` — pytest на синтетических данных.

## Повторное использование (из blagomed_cost/)
- Логика `app/core/calc.py` — формула, валидация, даты действия, extras.
- Подход `app/core/db.py` — миграции PRAGMA user_version, бэкап перед миграцией.
- Подход `app/core/onec.py` — COM/OData, вид цены «Закупочная», поставщик «ГАВРЮШКИН».

## Эталонные форматы (проверено контролёром на реальных файлах 24.11.2026)
- WB: лист «Себестоимость за 2026-11», заголовки строка 2, данные с 3, A=артикул WB, B=артикул поставщика, E=себестоимость. 83 строки.
- Ozon: лист «Себестоимость», заголовки строка 3, данные с 4, A=артикул Ozon, B=артикул продавца, D=себестоимость. 106 строк.
- Пишем только целевой столбец; нет цены — ячейку не трогаем, позиция в проблемные.
