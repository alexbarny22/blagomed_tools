# move_bot — передача товара в магазин (позиции «(МГ)»)

Окно со списком товаров общего склада: отмечаешь позиции и количество, бот в 1С УТ 11.5 (через OData) создаёт и проводит:

1. «Пересортица товаров» на общем складе: Товар → Товар (МГ);
2. «Передача товаров между организациями» позиций (МГ) по закупочной цене;
3. «Перемещение товаров» на склад магазина — если передача сама не переносит товар.

Запуск — `start.bat`. Он сам проверяет обновления на GitHub (`update.py`) и запускает бота.
Логин/пароль 1С — в `config.py` (в репозиторий не попадает; образец — `config.example.py`).

Веб-версия (`web.py`) открывает страницу с формой входа. Настройки входа — `WEB_USER` / `WEB_PASSWORD`
в `config.py`. Галочка «Запомнить логин и пароль на этом компьютере» оставляет сессию на 30 дней;
без неё вход действует до закрытия браузера.
