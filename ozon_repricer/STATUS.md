## Ключевые решения (не менять без владельца)
- Держим **цену селлера**, не «зелёную» (с Ozon Картой); конкурентов и парсинг витрины не делаем.
- Часть ассортимента ведёт **MPSpace**: отметка «Под MPSpace» (`rules.locked`) — такие товары программа не меняет никогда.
- По умолчанию **режим тренировки**; боевой режим включает только владелец.
- С 19.10.2026 у Ozon нет методов входа/выхода в глобальные акции: участие решает цена (≤ требуемой — участвует).
  Защита — минимальная цена (`min_price`, передаётся в Ozon) + закон 289-ФЗ. Подробности — навык `.cline/skills/marketplace-api/ozon.md`.
- Себестоимость: файл `Благомед_себестоимость_ГГГГ_ММ.xlsx` из `blagomed_cost.py`, все строки = закупка ×1.15. **Эти 15 % — реальные расходы владельца (аренда, оплата труда), часть себестоимости, а НЕ наценка.** Делитель должен быть **1** (у владельца выставлен вручную). Дубли артикула → берём большую.
- Ключи Ozon только в локальной базе, в репозитории — никогда (`PRESET_KEYS = {}`).
