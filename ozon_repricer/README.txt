РЕПРАЙСЕР OZON — БЛАГОМЕД
==========================

Программа раз в 30 минут (настраивается) забирает из Ozon цены всех товаров,
записывает их в базу (история для графиков) и по вашим правилам сама
возвращает цену в нужные границы или держит её на заданном уровне.
Работает на этом компьютере, интерфейс открывается в браузере.


УСТАНОВКА (один раз, ~5 минут)
------------------------------

Шаг 1. Python
   Если Python уже стоит (вы запускали на этом ПК свои .py скрипты) — пропустите.
   Иначе: откройте python.org -> Downloads -> жёлтая кнопка "Download Python".
   Запустите скачанный файл. ВНИЗУ ОКНА поставьте галочку
   "Add python.exe to PATH", затем нажмите "Install Now".

Шаг 2. Распакуйте архив
   Правой кнопкой по архиву -> "Извлечь всё..." -> укажите, например, C:\ozon_repricer
   Папку потом не переносите (если перенесёте — заново сделайте шаг 3).

Шаг 3. Двойной щелчок по файлу 1_INSTALL.bat
   Откроется чёрное окно, подождите надпись "Готово!" (1–3 минуты, нужен интернет).
   На рабочем столе появится ярлык "Repricer Ozon".
   Если Windows покажет синее окно "Windows защитил ваш компьютер" —
   нажмите "Подробнее" -> "Выполнить в любом случае".

Шаг 4. Ключи Ozon
   seller.ozon.ru -> Настройки (шестерёнка) -> API-ключи -> "Сгенерировать ключ".
   Роль: Admin (или ключ с доступом к ценам и товарам). Скопируйте Client-Id и ключ.

Шаг 5. Запуск
   Двойной щелчок по ярлыку "Repricer Ozon" на рабочем столе — откроется браузер.
   Вкладка "Настройки" -> вставьте Client-Id и Api-Key ->
   "Проверить подключение" (должно написать число ваших товаров) -> "Сохранить настройки".
   Наверху нажмите "Проверить сейчас" — на вкладке "Товары" появятся все товары.


РАБОТА ВМЕСТЕ С MPSPACE (по порядку)
------------------------------------

Часть товаров ведёт MPSpace, часть — эта программа. Чтобы они не перебивали
друг друга, товары MPSpace помечаются отметкой "Под MPSpace".

1. Программа стартует в режиме ТРЕНИРОВКИ: она всё считает, но цены в Ozon не меняет,
   а в "Журнале изменений" пишет, что изменила бы ("тренировка").
2. Отметьте товары, которые остаются в MPSpace: галочки слева в строках ->
   в тёмной панели "Отметить «Под MPSpace»". Или в Excel-файле правил поставьте 1
   в последнем столбце "Под MPSpace" и загрузите файл.
   Такие товары программа НЕ МЕНЯЕТ НИКОГДА: режим заблокирован, массовые
   операции и загрузка файла их пропускают. Мин/макс им задать можно —
   программа будет подсвечивать, когда MPSpace увёл цену за границы.
3. Остальным товарам расставьте правила (см. ниже). 1–2 дня смотрите журнал.
4. В MPSpace отключите товары, которые теперь ведёт эта программа.
5. Настройки -> снимите галочку "Тренировка" -> "Сохранить".
   Вверху появится зелёная плашка "Боевой режим".

Перевести товар из MPSpace сюда: сначала отключите его в MPSpace, потом снимите
отметку (карточка товара -> галочка "Под MPSpace", или панель -> "Снять отметку").
Через Excel-файл отметку можно только поставить, снять — только в программе:
так старый файл случайно не вернёт товар под управление.


ПРАВИЛА (вкладка "Товары", сохраняются сразу при вводе)
-------------------------------------------------------

Контролируемая цена — по умолчанию "цена со скидками продавца" (с учётом ваших
акций и скидок, точная). Можно переключить в Настройках на "≈ цену покупателя" —
это расчёт по индексу цен Ozon, близко к цене по Ozon Карте, погрешность ~2%.
(Ozon с ноября 2025 не отдаёт по API цену витрины напрямую.)

Мин и Макс — это границы ВАШЕЙ ЦЕНЫ СЕЛЛЕРА, то есть той цены, которую репрайсер
отправляет в Ozon (базовая цена; покупатель видит её уже с учётом ваших акций и скидок).
Репрайсер никогда не поставит цену ниже Мин (защита от убытка). Включённая в Настройках
галочка "Минимум -> в Ozon" дополнительно пишет ваш Мин в поле "Минимальная цена" Ozon.

Режимы:
 * Только следить     — ничего не меняет, подсвечивает "ниже минимума"/"выше максимума".
 * Держать в коридоре — если цена селлера вышла за Мин/Макс, возвращает её в границы.
 * Держать цену       — держит контролируемую цену на уровне "Цель" (± допуск, по умолчанию 2%):
   базовую цену программа пересчитывает с учётом ваших акций и скидок (как соотношение
   цены со скидками к базовой), чтобы контролируемая цена была равна цели, и не выходит
   при этом из границ Мин/Макс. Если мин/макс при включении не заданы — берутся
   автоматически: Мин = цель, Макс = текущая цена × 10.

Стратегия при максимуме (колонка "Стратегия" или карточка товара):
 * 0 — не превышать максимум: если цель выше достижимого при максимуме уровня,
   цена останавливается на максимуме, статус "упёрлись в максимум".
 * 1 — строгое удержание: можно поднять цену выше максимума, но не больше чем
   на настройку "Превышение максимума при строгом удержании, %" (в Настройках,
   по умолчанию 100%). Каждое превышение записывается в журнал с причиной.
По умолчанию безопаснее: 0.

Тип контроля (колонка "Контроль" или карточка товара):
 * "по настр." — как в Настройках (для большинства товаров достаточно).
 * "со скидками продавца" / "≈ цена покупателя" — индивидуально для товара.

Остатки — колонка в таблице (наведите на число — увидите разбивку FBO/FBS/FBP),
в карточке товара и в Excel-файле правил. Остатки подтягиваются из Ozon при каждой
проверке. Если Ozon не отдал остатки — показывается прочерк, на проверку цен это
не влияет (в "Событиях" появится предупреждение).

Требует внимания — метка и карточка-фильтр над таблицей. Причины: цена ниже минимума
или выше максимума, цель не достигается из-за максимума, изменение отложено из-за
подозрения на акцию с фиксированной ценой, ошибка при последней отправке цены в Ozon,
остаток 0 при активном правиле, красный индекс цен, автодобавление в акцию ниже минимума.
Ozon не принял настройку автодобавления. Наведите на метку — увидите список причин.

Теги — подписи товаров через запятую (например: "хит, весна"). Правятся в таблице
и карточке, массово — в тёмной панели "+ тег"/"− тег". Фильтры по тегу есть на
вкладках "Товары" и "Графики". Теги выгружаются в Excel-файл правил.

Быстрая настройка многих товаров: отметьте галочками строки (или галочку в шапке
таблицы — выбрать все) -> в тёмной панели укажите, например,
"Мин 95%", "Макс 130%" от текущей цены и режим -> "Применить".

Через Excel: "Скачать правила" -> правите столбцы Режим/Минимум/Максимум/Цена
удержания и новые столбцы Тип контроля, Стратегия при максимуме, Теги
(режимы: watch / guard / hold) -> сохраняете как CSV -> "Загрузить правила".
Файлы, выгруженные прошлой версией программы, загружаются как раньше.
(В самом конце файла — столбцы «Себестоимость, ₽» и «Автодобавление в акции (on/off/пусто)» — см. разделы про прибыль и акции.)


АКЦИИ OZON (вкладка «Товары», карточка товара)
----------------------------------------------
С 19.10.2026 Ozon решает участие товара в акции ВАШЕЙ ЦЕНОЙ: товар участвует, пока цена
не выше требуемой по акции («единая предельная цена»). Отдельных методов «войти / выйти»
у продавца больше нет, поэтому кнопки входа/выхода и режимы «входить / выходить из акций»
из программы убраны: выйти из уже идущей акции можно только подняв цену (для этого и нужны
Мин/Макс и «Цена удержания»).

Что видно в карточке товара (раздел «Акции Ozon»):
 * для каждой акции — название, даты, ТРЕБУЕМАЯ цена и ваша цена;
 * участник — «участвует, пока ваша цена ≤ X ₽»;
 * кандидат — «войдёт, если ваша цена ≤ X ₽»; если Ozon добавит сам — пометка «Ozon добавит
   сам по цене X ₽»;
 * если требуемая цена акции ниже вашего Минимума — красная метка «ниже вашего минимума»
   (и причина в «Требует внимания»);
 * если цена удержания ≤ требуемой цены кандидата — подсказка «при цене удержания товар
   попадёт в эту акцию».

Настройка акций теперь одна — «Автодобавление в акции» (в карточке, в таблице — колонка
«Акции», массово — в тёмной панели):
 * не трогать — как настроено прямо в Ozon;
 * разрешить автодобавление — Ozon сам добавит товар в подходящие будущие акции;
 * запретить автодобавление — Ozon не будет добавлять товар автоматически.
Эту настройку программа отправляет в Ozon при проверке. Это НЕ изменение цены: в «Журнале
изменений» появляется запись «акции: автодобавление», паузу и суточный лимит изменений
цены она не тратит. Товары «Под MPSpace» не трогаются; в режиме тренировки программа
только показывает в журнале «что сделал бы». Если Ozon не принял настройку — запись в
журнале, причина в «Требует внимания» и предупреждение в «Событиях».

В Excel-файле правил в самом конце появился столбец «Автодобавление в акции (on/off/пусто)».
Файлы старых версий загружаются как раньше: их настройки акций переводятся по тем же
правилам, что и при обновлении программы (1 — «запретить», 3+авто — «разрешить», иначе
— не трогать).


ПРИБЫЛЬ С ПРОДАЖИ И БЕЗОПАСНЫЙ МИНИМУМ (новое в версии 2026.11.24)
------------------------------------------------------------------
Программа умеет считать прибыль с каждой продажи и подбирать минимальную цену,
при которой вы не работаете в убыток.

Сначала настройте (Настройки -> «Прибыль и безопасный минимум»):
 * Налог, % от выручки — вашу ставку (например 6 или 15). Пусто — налог не учитывается.
 * Себестоимость из файла уже с наценкой — разделить на (по умолчанию 1.15).
 * Минимальная маржа, % (по умолчанию 10) — ею пользуется кнопка безопасности.

Себестоимость (сколько стоит товар, ₽ за штуку) задаётся тремя способами:
 1. В карточке товара: поле «Себестоимость» -> «Сохранить».
 2. Массово из Excel: кнопка «Загрузить себестоимость (Excel)» над таблицей.
    Подходит файл «Благомед_себестоимость_ГГГГ_ММ.xlsx» (лист «Себестоимость»,
    столбцы «Артикул поставщика» и «Себестоимость» — сопоставление по артикулу
    товара Ozon). Подойдёт и простой файл со столбцами «Артикул» + «Себестоимость».
    Так как в файле себестоимость уже с наценкой ×1.15, при загрузке она делится
    на число из настроек. После загрузки — отчёт: сколько загружено и какие
    артикулы не нашлись на Ozon. Если один артикул в файле встречается несколько
    раз с разной себестоимостью — берётся большая, а артикул попадает в отчёт.
 3. В Excel-файле правил появился столбец «Себестоимость, ₽» (в самом конце).

Прибыль — в таблице (колонка «Прибыль», руб. и %) и в карточке товара:
прибыль = цена со скидками продавца − комиссия Ozon − логистика − эквайринг
− налог − себестоимость. Комиссии и логистику Ozon программа берёт из Ozon сама
(схема FBO или FBS — по тому, где лежит остаток; логистика берётся по максимуму —
на всякий случай). Наведите курсор на число прибыли — увидите разбивку по статьям.
Если себестоимость ещё не заполнена — вместо прибыли будет прочерк (без ошибок).

Безопасный минимум — минимальная цена селлера, при которой с каждой продажи
остаётся прибыль не меньше маржи из настроек (считается из расходов и комиссий,
без учёта скидок акций). Где применить:
 * в карточке товара рядом с полем «Мин» — блок «Безопасный минимум» и кнопка
   «Применить → Мин»;
 * массово: отметьте товары галочками -> в тёмной панели кнопка «Мин. маржа → Мин».
Товары «Под MPSpace» программа не меняет: для них значение показывается, но
применить нужно вручную (в MPSpace).

ВАЖНО: перед применением убедитесь, что загружена себестоимость и указана ваша
ставка налога — иначе кнопка предупредит, чего не хватает.


ФОТО И СКРЫТИЕ ТОВАРОВ
----------------------
 * Фото товаров подтягиваются из Ozon сами (раз в сутки обновляются) и видны
   в таблице, на графиках и в карточке товара.
 * Убрать лишние товары из таблицы и графиков: отметьте их галочками ->
   в тёмной панели "Скрыть из таблицы". Или в карточке товара — "Скрыть из таблиц".
 * Вернуть: галочка "показать скрытые (N)" над таблицей -> отметить -> "Показать снова".
 * Скрытие — только для удобства просмотра: если у скрытого товара задано правило
   "Держать в коридоре"/"Держать цену", программа продолжит его выполнять.
   Чтобы программа не трогала цену, поставьте режим "Только следить".


ГРАФИКИ
-------
Вкладка "Графики" — все товары сразу. Период: 1 день, 3 дня, неделя, 2 недели,
месяц или свои даты "с ... по" (до месяца).
 * Наверху — сколько товаров подорожало/подешевело и столбики изменений по часам
   (для 1–3 дней) или по дням.
 * Ниже — маленький график по каждому товару: зелёная линия — цена со скидками,
   пунктир — ваши мин/макс/цель, треугольники — изменения цены программой
   (синие) или в тренировке (жёлтые). Сортировка и фильтры — над графиками.
 * Нажмите на график — откроется товар с большим графиком и тем же выбором периода.
   На большом графике наведите на треугольник — увидите причину изменения.
История копится с момента первого запуска программы, поэтому первые дни
графики будут короткими.


ЗАЩИТА ОТ ОШИБОК
----------------
 * После изменения цены товар не трогается 60 минут — Ozon пересчитывает цену не сразу.
 * Цена за один раз меняется не больше чем на 25%.
 * Не больше 8 изменений одного товара в сутки (лимит Ozon — 10 в час).
 * Если базовая цена поднята, а цена в акции не сдвинулась (акция с фиксированной
   ценой), программа останавливается по этому товару и пишет в журнал — проверьте акцию.
Все пороги меняются в Настройках.


ОБНОВЛЕНИЯ
----------
Программа обновляется сама: при каждом запуске (ярлык, автозапуск, 2_START.bat)
она проверяет GitHub и, если вышла новая версия, скачивает её и перезапускается.
Ключи Ozon, правила и история цен (папка data) при этом не трогаются.
Номер версии — вкладка "Настройки", раздел "Программа". Запись об обновлении
появляется на вкладке "События". Нет интернета — запускается текущая версия.


ВАЖНО
-----
 * Программа работает, только пока компьютер включён и она запущена.
   Закрыть браузер можно — проверки продолжатся.
 * Автозапуск при включении компьютера: двойной щелчок по 3_AUTOSTART_ON.bat
   (выключить — 4_AUTOSTART_OFF.bat).
 * Остановить программу: Настройки -> "Остановить программу".
 * Все данные — в папке data (repricer.db). Для резервной копии скопируйте эту папку.
 * Если что-то не работает: вкладка "События" и файл data\app.log.
 * Интерфейс: http://127.0.0.1:8765 (открывается только на этом компьютере).
