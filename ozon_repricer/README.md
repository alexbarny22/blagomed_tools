# ozon_repricer — репрайсер Ozon (цены своих товаров)

Раз в N минут (по умолчанию 30) забирает из Ozon цены всех товаров, пишет их в локальную
базу (история для графиков) и по правилам сама возвращает цену в нужные границы
(«коридор») или держит её на заданном уровне («удержание»). Ограничения: не более 8
изменений одного товара в сутки и шаг не больше 25% за раз, после изменения — пауза 60 минут.

Запуск на Windows: `1_INSTALL.bat` (один раз, ставит Python-окружение) → ярлык
«Repricer Ozon» (или `2_START.bat`). Интерфейс: http://127.0.0.1:8765.
Подробная инструкция для пользователя — в `README.txt`.

## Что в папке
| Файл | Назначение |
|---|---|
| `app.py` | Flask-интерфейс и API |
| `core/ozon.py` | Клиент Ozon Seller API (чтение/запись цен), режим `OZON_MOCK=1` для проверки без ключей |
| `core/db.py` | SQLite-база: товары, правила, история цен, журнал, настройки |
| `core/engine.py` | Логика: синхронизация, правила, автокоррекция |
| `templates/`, `static/` | Интерфейс и графики |

## Секреты
Client-Id и Api-Key Ozon вводятся в интерфейсе и хранятся только в локальной
`data/repricer.db` — в репозиторий они не попадают (`data/`, `venv/` в `.gitignore`).
При установке папка `venv/` создаётся сама.
