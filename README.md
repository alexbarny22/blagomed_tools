# blagomed_tools

Инструменты автоматизации Благомед — каждый проект в своей папке.

| Папка | Что делает | Связь с 1С |
|---|---|---|
| `move_bot/` | Передача товара с общего склада в магазин на Ленина (позиции «(МГ)») | OData `ut12` |
| `zakaz_postavshiku/` | Заказ поставщику (Гаврюшкин) из Excel-отчёта, PDF, отправка в МАКС | OData `ut12` |
| `blagomed_cost/` | Ежемесячный расчёт себестоимости МП для сервиса аналитики | COM / PDF |
| `prihod_po_foto/` | Бот MAX / Telegram: фото накладной поставщика → проведённое «Приобретение товаров и услуг» (нейросеть через агрегатор / GigaChat) | OData `ut12` |
| `zakaz_po_foto/` | Telegram-бот: фото этикеток коробок → заказы клиента ВБ/Озон | COM |
| `infografika/` | Генератор инфографики в браузере: 5 слайдов 900×1200 для WB/Ozon по фото товара + тексты карточки WB/Ozon (нейросети через vsellm, конструктор вёрстки, потолок расходов) | — |
| `direct_analytics/` | Аналитика Яндекс Директа на Timeweb: дашборд + Excel, предложения (исключить площадки РСЯ, минус-слова, стоп-фразы, ставки, смартфоны) с применением по галочке и откатом | — |
| `wb_reviews/` | Автоответы на отзывы Wildberries по звёздам | — |
| `vk_bot/` | VK-бот двух сообществ (прокат СР и прокат фотоламп): каталог, цены, контакты; самообновление | — |
| `ozon_repricer/` | Репрайсер Ozon: история цен своих товаров, автовозврат и удержание цены по правилам | — |

`move_bot` запускается своим `start.bat`, который сам скачивает свежую версию из своей папки.
Папки с пометкой «Восстановлено из переписки» в README собраны 01.11.2026 повтором всех правок
из чатов — перед заменой рабочих версий их стоит сверить.

Логины, пароли и токены хранятся только в локальных `config.py` / `config.ini` / `*_config.json`
и в репозиторий не попадают (в папках лежат образцы `config.example.*`).
