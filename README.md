# blagomed_tools

Инструменты автоматизации Благомед — каждый проект в своей папке.

| Папка | Что делает |
|---|---|
| `move_bot/` | Передача товара с общего склада в магазин на Ленина (позиции «(МГ)») в 1С УТ |

Каждый инструмент запускается своим `start.bat`, который при запуске сам скачивает свежую версию из своей папки.
Логины и пароли хранятся только в локальном `config.py` и в репозиторий не попадают (образец — `config.example.py`).
