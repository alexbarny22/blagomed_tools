# direct_analytics — аналитика и оптимизация Яндекс Директа

Раз в день бот забирает статистику Директа, показывает её на странице-дашборде и **предлагает конкретные изменения**,
чтобы реклама тратила меньше впустую. Изменения применяются в Директе **только после вашей галочки и кнопки «Применить»**.
Любое применённое изменение можно откатить одной кнопкой.

Кампании проката не анализируются (в названии есть «прокат» или «аренд» — настраивается в `config.py`).

## Что на странице отчёта

- **Сводка** за 7 / 14 / 30 / 90 дней с изменением к предыдущему такому же периоду: расход, показы, клики, CTR,
  цена клика, конверсии, цена конверсии. Фильтр «Всё / Поиск / Сети».
- **Предупреждения**: вчера расход 0 ₽ (кончились деньги?), резкий скачок расхода, кампания неделю без конверсий,
  выросла цена конверсии, упал CTR.
- **Графики** расхода и конверсий по дням.
- **Кампании** — таблица с сортировкой, стратегией и числом предложений.
- **Предложения бота** (за последние 30 дней):

| Что предлагает | Когда |
|---|---|
| Исключить площадку РСЯ | потратила ≥ 300 ₽ без конверсий, или CTR ≥ 10% при 20+ кликах без конверсий (ботовые клики) |
| Минус-слова | слово встречается в нескольких «пустых» поисковых запросах, или один запрос потратил ≥ 300 ₽ впустую. Слова из ваших ключевых фраз и из запросов с конверсиями бот не предлагает никогда |
| Остановить фразу | ≥ 600 ₽, 15+ кликов, 0 конверсий |
| Снизить ставку на 20% | цена конверсии фразы в 1,5+ раза выше целевой (только ручная стратегия) |
| Поднять ставку на 20% | 3+ конверсии вдвое дешевле целевой (только ручная стратегия) |
| Корректировка на смартфоны | конверсия со смартфонов в 1,5+ раза дороже, чем с компьютеров |

- **Журнал изменений** с кнопкой «Откатить».
- **Детали**: фразы, поисковые запросы, площадки РСЯ, устройства. Полные таблицы — в Excel (кнопка вверху).

Если в Директе нет конверсий (не подключены цели Метрики), бот покажет только площадки и минус-слова по
расходу — остальные предложения без конверсий делать нельзя.

## Файлы

| Файл | Что это |
|---|---|
| `direct_report.py` | главный скрипт |
| `dashboard_template.html`, `apply_template.php` | шаблоны страницы и кнопки «Применить» (скрипт сам кладёт их в папку отчёта) |
| `xlsx_writer.py` | запись Excel без дополнительных библиотек |
| `config.example.py` | образец настроек → скопировать в `config.py` |
| `run.sh` | запуск на Timeweb (обновление + отчёт) |
| `start.bat` / `demo.bat` | запуск на компьютере / просмотр с выдуманными данными |

Ставить ничего не нужно — только Python 3.6+ (на Timeweb уже есть).

## Шаг 0. Посмотреть, как выглядит (у себя на компьютере, 1 минута)

Дважды щёлкните `demo.bat`. Откроется страница с **выдуманными** данными. Кнопка «Применить» здесь не работает —
она работает, только когда страница открыта с хостинга.

## Шаг 1. Получить доступ к API Директа (один раз)

Всё делается под тем логином Яндекса, где ваши рекламные кампании.

1. **Принять соглашение API.** direct.yandex.ru → меню **«Инструменты» → «API»**
   (или сразу `https://direct.yandex.ru/registered/main.pl?cmd=apiSettings`) → прочитать и **принять соглашение**.
2. **Создать приложение.** Откройте `https://oauth.yandex.ru/?dialog=create-client-entry` →
   **«Для доступа к API или отладки»**:
   - Название: `Благомед аналитика`, почта — ваша;
   - Доступ к данным: **«Использование API Яндекс Директа (direct:api)»**;
   - Redirect URI (если спросит, на шаге «Платформы»): `https://oauth.yandex.ru/verification_code`;
   - **«Создать приложение»** → сохраните **ClientID**.
3. **Подать заявку.** Директ → **«Инструменты» → «API»** → вкладка **«Мои заявки»** → **«Новая заявка»**:
   ClientID из списка, ваша почта, описание (пример ниже), галочка согласия → **«Отправить»**.
   Рассмотрение — до 7 дней, статус виден там же.
   > Внутренний инструмент ИП для анализа собственных рекламных кампаний: ежедневная выгрузка статистики
   > (Reports API), анализ расходов и конверсий, исключение неэффективных площадок РСЯ, добавление минус-слов,
   > корректировка ставок. Изменения вносятся только после ручного подтверждения владельцем. Один экземпляр
   > приложения, работает на нашем хостинге, доступ только к своему аккаунту.
4. **Получить токен** (после одобрения): откройте
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENTID` →
   **«Разрешить»** → токен появится на странице. Сохраните его — повторно Яндекс его не покажет
   (но можно получить новый той же ссылкой).

## Шаг 2. Проверить у себя на компьютере (по желанию)

1. В папке `direct_analytics` скопируйте `config.example.py` → `config.py`.
2. Откройте `config.py` в Блокноте, вставьте токен в `DIRECT_TOKEN = "..."`, сохраните.
3. Дважды щёлкните `start.bat`. Через 1–5 минут откроется отчёт по настоящим данным.
   Если что-то не так — текст ошибки будет вверху страницы красным и в файле `direct_report.log`.

## Шаг 3. Поставить на Timeweb (каждый день сам)

**3.1. Загрузить файлы.**
Панель Timeweb → **«Файловый менеджер»**. Вы окажетесь в домашней папке (там же лежит папка сайта `blagomedi.ru`).
Создайте здесь папку `direct_analytics` — **рядом** с папкой сайта, не внутри неё.
Зайдите в неё и загрузите все файлы проекта плюс ваш `config.py`.

**3.2. Узнать путь к домашней папке.** В файловом менеджере вверху видна строка пути, например `/home/c/cl123456/`.
Запомните её — дальше это **ВАШ_ПУТЬ**.

**3.3. Настроить `config.py`** (открыть в файловом менеджере → «Редактировать»):
```python
OUTPUT_DIR = "ВАШ_ПУТЬ/blagomedi.ru/public_html/direct-k7p3x"   # придумайте свои 5 символов после direct-
REPORT_USER = "alex"
REPORT_PASSWORD = "придумайте-пароль"
```
Сохраните.

**3.4. Первый запуск вручную.** Панель → **«SSH-доступ»** → включите, если выключен → кнопка **«Открыть консоль»**
(или «Терминал»). В чёрном окне вставьте и нажмите Enter:
```
bash ~/direct_analytics/run.sh
```
В конце должно быть `Готово: ... (N предложений)`. Если пишет `python3: command not found` — напишите мне.

**3.5. Открыть отчёт:** `https://blagomedi.ru/direct-k7p3x/` (ваши символы). Браузер спросит логин и пароль из пункта 3.3.
Добавьте страницу в закладки.

**3.6. Включить ежедневный запуск.** Панель → **«Crontab»** → **«Добавить задачу»**:
- Периодичность: **каждый день**, время **06:00**
- Команда (ВАШ_ПУТЬ замените):
  ```
  /bin/bash ВАШ_ПУТЬ/direct_analytics/run.sh
  ```
Сохраните. Каждое утро отчёт обновится сам, а `run.sh` перед этим подтянет свежую версию бота с GitHub.

## Как пользоваться предложениями

1. Откройте отчёт → раздел **«Что улучшить»**.
2. Прочитайте причину под каждым пунктом, поставьте галочки на том, с чем согласны («Выбрать все» — по группе).
3. **«Применить выбранные»** → проверьте список → **«Да, применить»**. Под каждым пунктом появится ✓ или причина ошибки.
4. Передумали — **«Журнал изменений»** → **«Откатить»**.

Применённые предложения в следующих отчётах не повторяются. Предложения старше 4 дней применить нельзя —
данные могли устареть, дождитесь свежего отчёта.

**Важно про стратегии.** В кампаниях с автостратегией (оплата за конверсии, максимум конверсий и т.п.) Директ сам
управляет ставками, поэтому бот предлагает там только площадки, минус-слова, остановку фраз и корректировку смартфонов.
Ставки предлагаются только для кампаний с ручной стратегией.

## Настройки (`config.py`)

- `EXCLUDE_WORDS` / `EXCLUDE_IDS` / `INCLUDE_ONLY_IDS` — какие кампании смотреть.
- `GOALS` — номера целей Метрики, которые считать конверсией (пусто — ключевые цели кампаний).
- `TARGET_CPA` — целевая цена конверсии, ₽ (0 — средняя по аккаунту).
- `WASTE_MIN_COST` — от какой суммы «без конверсий» считать сливом (по умолчанию 300 ₽).
- `BID_STEP` — максимальный шаг изменения ставки, %.

## Безопасность

- Токен Директа лежит только в `config.py` и `apply_settings.json` в папке `direct_analytics` — она вне `public_html`,
  из интернета её не открыть. В GitHub эти файлы не попадают.
- Страница отчёта закрыта логином и паролем. Кнопка «Применить» умеет выполнять только предложения, подготовленные ботом,
  — произвольные команды в Директ через неё отправить нельзя.
- Каждое изменение записывается в журнал (`actions_log.json`) с временем и IP.
