# Wildberries API — выжимка

Пока не заполнено: наши боты для WB работают без этой выжимки (wb_reviews — отзывы).

Когда понадобится (репрайсер WB, остатки, акции) — заполнять по образцу `ozon.md`:
- в начале «Сверено: дата, источники»;
- разделы по задачам (цены, остатки, акции, отзывы…), в каждом: метод, запрос, ответ, лимиты;
- пометка **⚠ НЕ ПОДТВЕРЖДЕНО** для всего, что не сверено с живым ответом или официальным источником;
- в конце «Изменения площадки (журнал)».

Официальные источники для сверки: dev.wildberries.ru (документация), раздел новостей API там же.
