# API маркетплейсов — выжимка вместо документации

Документация Ozon и WB огромная: чтение её целиком съедает токены на каждом следующем шаге задачи.
Здесь собрано только то, что нужно нашим ботам, со сверкой по источникам и датой.

## Как пользоваться

1. Открой ТОЛЬКО файл нужной площадки:
   - `ozon.md` — Ozon Seller API (цены, остатки, товары, акции);
   - `wildberries.md` — Wildberries (пока заготовка).
2. **Документацию площадки целиком НЕ читай.**
3. Если нужного метода/поля здесь нет, или живой ответ площадки не совпал с описанием:
   - прочитай ТОЛЬКО страницу этого метода (не весь раздел);
   - **допиши проверенный факт в файл площадки** (метод, поле, дата проверки, источник) — чтобы следующий раз не искать;
   - упомяни это в отчёте пользователю.
4. Пункты с пометкой **⚠ НЕ ПОДТВЕРЖДЕНО** нельзя использовать в коде, который меняет данные на площадке
   (цены, участие в акциях), пока не подтвердишь по шагу 3 или не спросишь пользователя.
5. У каждого раздела стоит «Сверено: дата, источник». Если с даты прошло больше 3 месяцев,
   а живой ответ ведёт себя странно — сначала проверь раздел «Изменения площадки» в файле.

## Как дополнять

- Новый факт → в нужный раздел файла площадки + строка в «Изменения площадки», если это изменение API.
- Указывай источник: официальная новость/канал площадки, живой ответ API (дата), библиотека (имя, дата коммита).
- Не переписывай файл целиком — правь только нужный раздел.
- Новая площадка (Яндекс Маркет и т.п.) — новый файл `<площадка>.md` по образцу `ozon.md` и строка в «Как пользоваться».
